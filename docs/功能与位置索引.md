# 鸣潮助手 (WutheringWavesTool) 功能与位置索引

> 本文档标记本项目（Download\2\WutheringWavesTool）所有功能模块、UI 视图、服务、数据层及基础设施的**代码位置**，便于快速定位与后续维护。
> 包根：`cn.tealc.wutheringwavestool`（位于 `wwt-app/src/main/java/...`）
> 资源根：`wwt-app/src/main/resources/cn/tealc/wutheringwavestool/`

---

## 1. 项目结构总览

多模块 Maven 工程，三个子模块：

| 模块 | 路径 | 职责 |
|------|------|------|
| `wwt-app` | `wwt-app/` | 主应用：JavaFX UI、业务逻辑、数据访问、本地配置 |
| `wwt-kuro-api` | `wwt-kuro-api/` | 库街区(KuJieQu)/启动器 API 封装：`com.kuro.kujiequ`、`com.kuro.launcher` |
| `wwt-game-resource-core` | `wwt-game-resource-core/` | 游戏资源下载/更新/服务器切换内核（`cn.tealc.wwt.game.resource`） |

技术栈：Java 25/26（module-info）、JavaFX（ControlsFX、MaterialFX 图标）、MVVMFX、SQLite（JDBC）、Maven 多模块。

## 8. 依赖模块详解

### 8.1 `wwt-kuro-api`（库洛 API，`com.kuro`）
- `com.kuro.kujiequ`：Auth / Calculator / Role / Sign / Tower / User 六大 API（`api/`）、`KujiequManager`、`KujiequApiContext`、`ApiUtil`、`ApiConfig`，异常 `AccessTokenException`/`ApiDecryptException`/`TokenExpiredException`。

- 模型包：`model/roleData`、`model/calculator`、`model/towerData`、`model/slash`、`model/sign`、`model/resourcebriefing`、`model/newTowerData`。

### 8.2 `wwt-game-resource-core`（资源内核，`cn.tealc.wwt.game.resource`）
- 对外入口：`GameResourceUpdateService`、`GameServerSwitchService`、`GameDownloadSource`、`DownloadOptions`、`BandwidthLimiter`、`ResourceContext`。
- 新版模型/监听：`model/*`、`ResourceProgressListener`、`ServerSwitchProgressListener`、`ResourceCompletionListener`。
- 旧版内核（`internal/legacy`）：配置加载 `config/*`、下载 `download/*`、流程 `flow/*`（CheckUpdate/Predownload/Repair/ResCheck/Update）、模型 `model/*`、补丁 `patch/*`、任务 `task/*`、工具 `util/*`。
- 原生依赖：`resources/kr/hpatchz.exe`、`resources/kr/KRApp.conf`（Windows 补丁执行器）。
